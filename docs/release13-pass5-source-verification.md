### Annex 5 scorecard legend — PDF pp. 116–117 (internal printed pp. 101–102)

The source uses a traffic-light scheme with five status meanings, not only three performance bands:

- **Red / target not met:** 0–50% achieved; for qualitative targets, no significant action initiated. The stated action point is substantial effort to improve.
- **Yellow / target partially met:** 51–79%; for qualitative targets, significant action initiated and some progress made. The stated action point is to maintain and optimize performance.
- **Green / target substantively met:** 80–100%; for qualitative targets, significant progress made. The stated action point is to sustain high delivery.
- **No performance data available:** data completion/submission is needed.
- **Not applicable for the monitored period:** target is not applicable in that period.

Pass 4’s previous shorthand table of three percentage bands was incomplete. The full legend above should be used in learning content. A blank status field must not be inferred to mean “not met.”

### Annex 3 M&E matrix — PDF pp. 93–112

The extractable table confirms that this is a planned monitoring framework with indicator, baseline, year-target, means-of-verification, objectively-verifiable-indicator and agency columns. It contains TBD values and source notes such as an ongoing survey/research pipeline. These must remain TBD/planned rather than being converted into numeric baselines or achieved outcomes.

The matrix includes the three strategic goals, with Goal 3 phrased as: “Persons affected by mental health conditions are able to exercise the full range of human rights.” One visible Goal 3 indicator is the number of facilities providing mental-health care with a functioning Institutional Review Board (IRB); its targets refer to pilot sites, DOH-retained Level 3 hospitals, and a private hospital in regions. The detailed target-year/column alignment should still be verified row-by-row before quiz keys or app data are authored.

The M&E annex and the main narrative use both goals and outcome statements. Do not treat the four strategic pillars as if they were four goals, and do not infer a one-to-one mapping between pillars and outcome rows.

### Annex 5 scorecards — PDF pp. 115–124

- The annex names 13 scorecards: consolidated/overall, PCMH, DOH, NCMH, PHIC, DOLE, DILG, DepEd, CHED, TESDA, DSWD, CSC, and CHR.
- The source describes quarterly monitoring, updating and reporting as the intended scorecard process.
- Scorecards contain planned targets and status fields; the existence of a target or scorecard does not prove the target was achieved.
- Exact row/column values for each agency scorecard have not all been visually verified in this pass.
